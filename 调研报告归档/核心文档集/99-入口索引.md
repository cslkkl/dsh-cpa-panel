## 1. 一句话系统定位

**养号自动化 + 多渠道中转 ProxyAPI：在 Windows 单机上纯启动一个 exe 主服务，由 DSH 插件作唯一界面，托管进程、管理「渠道×账号×模型」独立调用单元、自动签到/做任务/保活。**

- 无 Docker、无第二个网页后台、无命令行手动配置。
- 唯一 UI = DSH 插件页；插件渠道的 panel.html 仅保留为 zcode 验证码 + OAuth 回调技术页。
