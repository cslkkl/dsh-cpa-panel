# 调研报告归档/ — 规则层

继承根规则，见 [../AGENTS.md](../AGENTS.md)。

本目录是**只读历史**，产自调研与设计阶段：

- **不要更新、不要"顺手修正"、不要同步代码变化** —— 它是某个时间点的留痕，改了就失去追溯价值。
- 唯一允许的改动：修正**事实性错误**（失效的绝对路径、错误的内部状态标注），且必须在提交信息中说明。
- 新结论、新计划写进 [../docs/](../docs/)，不写在这里。
- 各文档开头的「基线 commit」是锚点有效性的前提，不要改动。
- 这里不做双件要求：目录结构与用法见 [README.md](README.md)。
